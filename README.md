# 星宿演武 v0.3.0

横屏俯视角太空舰队战斗原型：编队、配装、部署后，亲自驾驶旗舰并让僚舰自主作战，也可切换 AI 观战。采用 Canvas 2D；浏览器与微信小游戏共用战斗、导航和界面代码，无 npm 运行依赖。

v0.3 重做四舰原创美术、星云背景、多喷口推进及武器命中效果；战场改为友军从下方、敌军从上方入场，并提供可实射的武备试炼场。

## 本地启动

需要 Python 3。进入项目目录后运行：

```sh
npm run preview
```

也可直接执行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 [本地预览](http://127.0.0.1:8765)。建议使用横屏窗口；手机竖屏时显示横置提示。

首次流程：选择友方或对手编队 → 选择舰位和舰型 → 点「装入所选舰位」→ 可选「配装」→「进入战场」（紧凑界面显示「部署舰队」）→ 将舰卡拖进下方蓝色部署区，或点「快速布阵」→「出击」。未布置的友舰留作预备队；至少部署一舰才能出击。也可先进入「试炼场」，对不会还击的靶舰练习武器与驾驶。

## 已实现功能

- 双方各 1–4 艘舰船，含预备舰总预算不超过 60 DP。
- 4800 × 3000 世界空间、避开底部操作区的跟随镜头、战术全图、小地图、离屏敌舰方向及距离提示；滚轮与屏幕按钮缩放，部署图、战术图和 AI 观战支持双指平移与缩放。
- 独立双触点摇杆：左杆推进，右杆瞄准并开火。舰艏按角加速度逐渐转向，移动速度、舰艏朝向和炮塔瞄准分别计算。
- 手操旗舰与 AI 观战切换；观战支持 1×/2×。切换旗舰保留舰船位置、速度、朝向、结构与幅能状态。
- 初始拖舰部署、15° 朝向调整、旗舰指定、留备；友方位于下方并朝上，敌方位于上方并朝下。战术暂停中从友方下边缘投入预备舰，检查边界、舰体间距及附近敌舰。
- 战术图支持选择友舰、接管、前往、集火、护航和撤离，紧凑横屏同样提供撤离。向旗舰下达有效战术命令后切换 AI 执行，可再次接管恢复手操。
- 按尺寸和类型匹配炮位的武器替换、OP 装配预算、散逸与容量升级；三个武器组分别设置手动或自动。
- 实弹、追踪导弹、脉冲与连续光束，炮位射界、导弹弹药与燃料、点防御拦截、友舰遮挡。
- 动能、高爆、能量和破片伤害；六区局部装甲、定向护盾、软/硬幅能、过载和主动散幅。玄甲可启动「玄甲阵」。
- 武备试炼场使用真实战斗模拟：靶舰不会还击，可测试推进、转向、制动、武器命中、护盾、幅能及散幅，也可让友舰 AI 作战。战斗结算显示胜负、用时和友舰结构伤害，没有定时强制判胜。
- 本地保存编队、配装与声音开关，使用独立的 `xingxiu.settings.v2` 存储项。删除舰位保留其余舰船配装。暂停、切换页面和退至后台会清空驾驶输入。

四舰参数来自当前舰船目录，速度单位为世界单位/秒，加速度为世界单位/秒²：

| 舰船 | 定位 | DP | 最高速度 | 推进加速度 | 最大转速 | 转向加速度 |
|---|---|---:|---:|---:|---:|---:|
| 虾兵级·赤螯 | 快速侧翼游击 | 10 | 120 | 110 | 60°/秒 | 90°/秒² |
| 天兵级·羽林 | 中型火力护航 | 16 | 90 | 60 | 30°/秒 | 60°/秒² |
| 星宿级·参水猿 | 高科技能量突击 | 18 | 100 | 90 | 40°/秒 | 100°/秒² |
| 蟹将级·玄甲 | 重甲重炮阵线 | 26 | 30 | 20 | 12°/秒 | 12°/秒² |

四舰采用新绘制的原创俯视图片与原创星云背景。按上表顺序，主推进喷口数为 5 / 3 / 3 / 5；尾焰随推进、制动、侧移和转向变化。独立渲染器表现炮口闪光、弹体拖尾、导弹与光束、盾面涟漪、装甲火花、爆炸冲击与碎片，并提供有限镜头震动；视觉随机数与战斗模拟独立。

## 操作

| 操作 | 触屏 | 桌面键鼠 |
|---|---|---|
| 推进 | 左摇杆 | WASD |
| 瞄准与开火 | 右摇杆拖出死区 | 鼠标瞄准、左键开火 |
| 切换护盾 | 护盾按钮 | 鼠标右键 |
| 制动 | 按住「制动」 | 按住 C |
| 主动散幅 | 长按「散幅」约 0.35 秒 | V |
| 玄甲阵 | 玄甲专属按钮 | F，仅玄甲可用 |
| 选择手动武器组 | 点击组名 | 1 / 2 / 3 |
| 切换本组自动开火 | 点击组旁自动/手动 | R |
| 进入/退出战术暂停 | 战术图 / 继续战斗 | 空格 |
| 暂停/继续驾驶 | 顶栏按钮 | 点击顶栏按钮 |
| 镜头缩放 | ＋ / − | 滚轮或 ＋ / − |
| 观察地图 | 部署图、战术图或 AI 观战中拖动；双指平移缩放 | 在部署图、战术图或观战中拖动 |
| 关闭帮助/配装 | × | Esc 或 × |

散幅时护盾关闭、不能开火。软幅能可持续散逸，硬幅能需要关闭护盾才能消退；幅能满会过载。默认主炮组手动，副炮和防御组自动。鼠标/右杆手动开火只控制选中的手动组；持续按左键时可用右键切盾。微信适配器已接入 SDK 的鼠标、滚轮与键盘事件，并抑制触摸和鼠标重复输入；可用性仍取决于宿主事件支持。

## 微信开发者工具

导入本项目目录，项目类型选择「小游戏」。`project.config.json` 已配置 `miniprogram/` 为代码根目录，入口为 `miniprogram/game.js`，横屏配置在 `miniprogram/game.json`。

沿用已有测试 AppID 和基础库 3.8.3 配置。若当前账号没有该 AppID 的权限，请换为你有权限的小游戏 AppID；这是导入配置问题，不影响浏览器预览。若工具尝试下载其他基础库或启动超时，检查「详情 → 本地设置 → 调试基础库」，按本机可用版本调整后重新编译。

**v0.3 验证状态：** 已在本地浏览器 1280 × 720 与 844 × 390 横屏实测：拖舰朝上部署、实弹靶场、主炮自动开火、旗舰指定和 AI 对战至胜负结算。浏览器控制台无运行错误。微信开发者工具已编译并显示新版界面，未见游戏错误；本次自动化点击、拖动画布仍没有响应，因此微信原生交互尚未确认通过。

**实体手机尚未实测。** 扫码预览、真机双指手感、刘海安全区域、不同机型帧率与扬声器听感仍需验证。

## 原创声音

内置 68 个原创程序合成 WAV：界面、实弹、导弹、脉冲、爆炸、胜利、护盾、低音推进、侧推、散幅、系统、光束及金属/护盾/重型/光束灼烧/光束撞盾/等离子命中。总计 1,182,232 字节，22,050 Hz、单声道、16-bit PCM。轻、中、重火炮分别使用开火与舰体命中音色，每类三种变体；混音为命中预留四个声道。护盾近场音色保持不变。所有战场单次声均按镜头所在的世界坐标衰减，650 单位以外使用低通远场版本；开火归属和缩放不会绕过距离衰减。光束最多两个低音量持续声部，防御光束更轻，停火淡出、暂停与后台立即停止；重击短暂压低光束背景。

浏览器与微信适配器均提供音量参数与并发池，并对密集重复及重叠声音限流、衰减；声音不可用时不阻断战斗。可在整备页关闭声音。

```sh
python3 tools/generate_audio.py
```

以上命令仅使用 Python 标准库重新生成音效与 `AUDIO.md`，无需下载音频素材。

## 测试与文件

使用支持 `node --test` 的 Node.js（建议 20 或更新版本），无需 `npm install`：

```sh
npm test
```

当前 76 项自动回归全部通过。覆盖战斗/运动/武器数值、纵向部署与镜头约束、编队和配装、真实试炼、双触点、暂停清输入、换旗舰保状态、预备舰、30/60 Hz 轨迹一致及 120 Hz 单次输入。原生适配层 VM 集成测试通过真实游戏模块验证 wx 拖舰、双触点、键鼠、前后台和音频池。渲染测试覆盖事件消费、粒子上限及绘制数值；mock Canvas 测试不等同于真实设备画质或性能验收。
